# NIKKE Photos v1.0

NIKKE Photos(desktop version) 是一款面向《胜利女神：新的希望》(下称国服)的 Windows 本地桌面工具，用于管理妮姬档案、录入装备词条、生成练度统计、计算洗练资源和练习装备洗练。完整客户端提供国服装备采集流程：读取游戏中的装备信息，经过人工核对后写入本地档案。

本项目支持 Windows 10 2004（版本号 19041）及以上的 64 位系统，暂不支持 Windows 7、Windows 8、32 位 Windows。安装包内置界面、计算工具、装备采集所需 Python 运行环境及识别资源，安装后无需另装 Node.js 或 Python。

## 功能入口

| 主入口 | 功能 |
| --- | --- |
| 角色管理 | 浏览全部角色，筛选和搜索，查看我的妮姬，制作角色卡 |
| 数据录入 | 编辑练度、魔方、收藏品和装备词条，使用图片识别辅助录入 |
| 数据统计 | 汇总装备词条，调整表格名单和顺序，预览或导出统计图与表格码 |
| 妮姬工具 | 红球计算器、洗词条计算器、装备洗练模拟器、订制模组记录 |
| 装备采集 | 选择国服角色，采集装备截图，核对识别结果并确认写档 |
| 更多 | 管理存档和方案，新增自定义妮姬，导出 BOT 分享码，查看关于与更新记录 |

## 启动与首次使用

系统要求：Windows 10 2004（版本号 19041）及以上的 64 位系统。装备采集需要国服桌面端游戏及符合页面要求的画面设置。

推荐画质：全屏幕模式(装备采集刚需 1920x1080 分辨率全屏幕模式)，抗锯齿：8x，人物分辨率：高

提供三种 Windows x64 分发形式，程序功能相同：

| 文件 | 使用方式 |
| --- | --- |
| NIKKE-Photos-v1.0-Windows-x64-Setup.exe | 运行安装向导，选择目录，完成后从开始菜单打开 |
| NIKKE-Photos-v1.0-Windows-x64.zip | 完整解压，运行文件夹内的 NIKKE Photos.exe |
| NIKKE-Photos-v1.0-Windows-x64.tar.gz | 使用支持该格式的工具完整解压，再运行 NIKKE Photos.exe |

压缩包版无需安装，请保留同目录的 resources 等文件，不要只单独拷贝一个 EXE。三种形式均使用独立的用户数据目录，压缩包版也不会自动把档案放进解压目录。分发目录提供 SHA256SUMS.txt，可用于核对三个文件。

更新时可覆盖安装到原目录；存档放在独立的用户数据目录中。软件不会自动下载更新，新版本仍需手动下载安装。

建议首次使用按以下顺序操作：

1. 在“更多 → 存档管理”新建自己的存档，填写名称和同步器等级。
2. 到“数据录入”搜索角色，填写练度与装备词条；也可以先导入已有档案。
3. 四个装备部位都有词条后，到“数据统计”选择角色，生成统计表。
4. 在“妮姬工具”中使用计算器或模拟器；需要批量读取国服装备时使用“装备采集”。

软件数据主要保存在本机，没有云账号同步。切换存档会切换当前角色记录；截图缓存、角色档案和资源收入记录是不同的数据，具体见文末备份说明。

## 角色管理

### 全部角色与筛选

角色列表支持按中文名、英文名、资源号、拼音和别名搜索，可按企业、爆裂阶段、武器、稀有度、属性和职业组合筛选，并提供国服已实装、珍藏品、超标准等筛选项。

“国服已实装”依据独立维护的国服名单，不会联网查询实时实装进度。各页面筛选相互独立，不存在影响整套软件的全局国服开关；关闭某页筛选不会删除已录入的角色数据。

列表提供显示大小调整。进入角色详情再返回时，会话中的搜索和筛选条件会保留。

### 我的妮姬

“我的妮姬”集中展示当前存档中四个装备部位都已录入词条的角色，支持搜索、属性分组和其他筛选，方便查看已完善记录。它不是游戏账号的实时拥有列表，显示范围取决于本地录入情况。

### 角色详情与角色卡

点击角色可查看角色卡，并调整立绘、缩放、位置、显示模块和布局。可用的立绘取决于角色本地资源；没有图片时使用缺省显示。

支持放大预览和 PNG 导出。默认 3 倍导出为 2208 × 3288 像素，可在导出设置中调整倍率、背景、署名及文件名。角色卡展示依赖当前存档记录，导出图片是当时的快照。

## 数据录入

### 练度与装备编辑

左侧搜索并选择角色，右侧填写对应记录，包括突破与核心、好感度、战斗力、技能等级、魔方、收藏品及四件装备词条。

同步器等级和职业／企业研究等级属于存档共通信息，会供该存档下的角色使用。具体可填范围以输入框提示为准，越界数据会提示；空白表示未填写，不应随意用零代替。

录入页的有效修改会自动保存到当前本机存档。若出现“尚未保存”等错误提示，应先修正或处理错误，不能把当前草稿视为已经保存。

左侧的“国服已实装”开关只控制录入页的候选列表。页面还提供方案应用、同步已完善角色技能、查看角色详情及清空该角色数据等入口；涉及批量或清空的操作以弹窗确认范围为准。

### 装备词条规则

四个部位分别录入三栏词条，每栏选择类型和档位，数值按对应档位表显示。

- 同一件装备的非空词条类型不能重复，空词条可以重复。
- 有任意词条时，第一栏必须有词条；第二、三栏允许为空。
- 整件装备可以全空，表示未录入或尚无词条。
- 后两栏仍有词条时，不能单独清空第一栏；需要清空整件时使用“清空本件”。

普通编辑、OCR 应用、采集写档和新档案导入都会检查装备结构。历史异常记录不会在读取时自动清掉；修改该件装备时需先纠正，未改动的旧数据仍可保留。

### 装备图片识别

每个装备部位提供“图像识别”。打开后可以选择本地图片、粘贴图片，或通过截图入口选择游戏窗口获取装备画面。

图片应包含完整装备面板及 OVERLOAD 标识，保持文字清晰。识别后按三栏显示候选类型、档位和数值；标记“需核对”的行要对照原图检查，可手动修改后再应用。

弹窗支持查看原尺寸图片和下载本次图片。识别候选不会因为出现而自动成为正式记录；应用时仍受装备结构校验，不确定或失败的识别不能当作已确认结果。

## 数据统计

统计表将每位角色四件装备的同类词条数值相加，展示优越、攻击、装弹、暴伤、暴率、蓄速、蓄伤、命中、防御及阶数。阶数为有效词条档位之和；单元格颜色按累计档位规则显示。

### 名单与排序

点击“编辑表格角色”添加或移除角色，可搜索、筛选、查看已选择名单并填写表格署名。主表支持按属性排列，也可以拖拽行调整顺序。

可参与统计的角色须四个装备部位各至少有一条词条，不要求十二栏全满。

已选角色后来清空某件装备时，软件会：

1. 保留该角色的选择和顺序。
2. 在暂停区列出该角色，暂不将其放进统计表、放大预览、PNG 和表格码。
3. 提供“补齐装备”和“移出名单”入口。
4. 补齐后按保留的顺序自动恢复。

保存装备修改后，表格会按当前存档重新计算，无需重新选择角色；未保存的草稿不参与更新。

### 预览和导出

“放大预览”用于核对完整表格；“导出图片”生成高清 PNG；“导出表格码”生成供 BOT 使用的名单配置码。

PNG 是导出时的快照，后续录入变化不会改写已保存图片，需要重新导出。表格码只包含角色身份和行序，不包含具体词条数值；BOT 使用它自己接收的角色数据生成表格。

## 妮姬工具

工具页提供四个并列入口，默认打开红球计算器。切换工具时已加载的计算器和模拟器会保留当前实例；重新加载软件或离开整个工具页后的恢复规则，取决于各工具自身的草稿保存方式。

### 红球计算器

根据普通／困难战役进度和基地等级，查询六项每小时产出以及芯尘提升参考表。支持进度选择、升降序排列和半档提升节点显示。

修改普通战役进度后，输入区和参考表会同步更新。计算使用随软件部署的本地数据，页尾显示数据版本，不会自动抓取最新游戏章节或产出表。

### 洗词条计算器

用于规划装备目标和估算后续洗练资源，不会操作游戏或把计算结果自动写回角色档案。

单装备模式可配置当前词条、目标池、必选、锁定和强制保留，选择旧／新规则，计算期望成本、推荐下一步、阶段和决策树。

四装备模式可分别设置四件装备，配置角色全局条件、目标预设及跳过部位，执行预算内的装备分配规划，并导出本地 Excel 结果。也可从当前档案选择已完善角色，预览后将四件装备复制进工具；只替换工具盘面，不改角色原档案。

支持的资源策略包括常规洗练和自订秘钥策略。秘钥模式有独立的目标与约束范围，不支持的输入会明确提示。四装备秘钥模式采用近似规划，不保证全局最优。

“保留当前为原盘面”等洗练前后对比操作，可比较两边剩余期望，并应用或恢复工具盘面。修改参数后旧对比会失效，需要重新计算；比较不重复计入已经花掉的资源。

高复杂度计算存在状态数、迭代数、条件数和运行时间限制。页面会保留相关提示，超限或未收敛不能当成有效结果。工具可以恢复部分输入草稿，决策结果需要重新计算。

### 装备洗练模拟器

独立入口，用于练习洗词条、洗数值和锁定策略。支持随机或自定义初始状态、单件或四件装备，以及旧／新规则。

自定义模式可手动配置词条和档位，也可通过“选择角色装备／选择角色”复制当前档案中已完善角色的初始装备。该操作只读取快照，不修改角色档案。

开始后可使用永久石头锁和一次性秘钥锁，选择保留原词条、应用新结果，或保留原词条并继续洗练。工具分别记录订制模组与自订秘钥消耗，并显示目标达成情况、实际用量和支持范围内的理论参考。

支持重新开始和结束练习。切换模拟规则会重置本局，重新加载页面或切换主题也可能重置；模拟过程不是玩家存档，不应当作长期记录。随机结果不预测游戏中下一次洗练。

### 订制模组记录

记录每天实际获得的订制模组和自订秘钥，仅记录收入，不推算库存或记录支出。

- 日期默认今天，可以补录历史日期；每天一条，选择已有日期可修改原记录。
- 数量为非负整数，至少填写一种资源；空白是未填写，填写 0 才表示确认零收入。
- 支持确认删除某一天记录和导出 JSON 备份。
- 展示累计、最近 7 天和最近 30 天收入；日均按对应资源实际填写的天数计算，不直接除以 7 或 30。

记录独立于角色存档，切换角色存档仍使用同一份资源记录。桌面文件写入前保留上一版备份；当前提供备份导出，没有界面内的资源记录文件导入功能。

## 装备采集

### 使用条件

使用 Windows x64 完整客户端，采集运行环境已内置。游戏为国服《胜利女神：新的希望》，保持 1920 × 1080、游戏必须未最小化，启动前需要手动使游戏界面处于大厅（由于是初版，后续会进行优化）；可以被其他窗口遮挡。

该功能只提供独立国服名单中的内置妮姬，不提供国服／全部切换，也不采集自定义角色。名单由开发者维护，不会联网判断新角色是否实装。后续更新请关注本项目或分发的网盘链接

### 采集流程

1. 点击“初始化并连接游戏”，检测并连接目标窗口；出现多个候选时先选择正确窗口。
2. 在“选择角色”中搜索、筛选和勾选本轮妮姬，也可选择当前筛选结果。
3. 点击“启动所选角色采集（UAC）”，由本人确认 Windows 提权提示。
4. 在“执行进度”查看当前角色、装备部位和识别进度；可按页面提供的操作暂停、继续或停止，快捷键可在采集设置中配置。
5. 进入“结果核对”，逐件对照截图，修正词条或采用已核对的候选。
6. 查看目标存档和替换范围，主动确认写入本地档案。

采集会读取角色装备并在后台识别，不执行日常任务或消耗游戏资源。未知画面、身份或输入状态无法确认时会停止或提示，不应把跳过当作采集成功。

### 核对、写档与清理

识别草稿不会自动覆盖正式档案。未确认结果可保留原档案值，明确空词条与识别失败也会区别处理；写入前还会校验合并后的装备结构。

写档成功后，本轮全部选择、进度、草稿和结果会清空，回到准备状态；取消或写档失败不会按成功处理。同次打开期间，中断任务可从页面提供的入口继续；关闭后重开会清空上轮采集会话，已写入档案、导出文件和设置保留。

采集设置中可管理快捷键、截图位置、装备结果图清理时机、异常图保留时间及容量上限。待核对截图受到保护；结束核对后按清理策略处理。容量不足会提示，不会强行删除受保护图片。

## 更多

### 存档管理

每份存档有独立的角色记录、名称、备注、同步器等级与研究信息。支持创建、切换、编辑、删除和查看存档中的角色；默认存档不可删除。

支持导出当前档案 JSON，以及导入本软件档案、BlaBlaLink 账号 JSON 和 NIKKE Workshop 图鉴 xlsx。文件也可以拖入主界面或工具页面识别，随后选择目标并确认。

导入可以新建存档或覆盖指定存档。覆盖会替换目标角色数据，并非逐条追加；以确认弹窗为准，操作前建议导出原档案备份。导入方案按既有合并规则处理，重名方案会改名保留。

未知角色 ID 会明确跳过，不写进档案；整份文件没有可识别角色时会拒绝，避免覆盖成空档案。非法装备结构会阻止导入并说明原因，失败时不会先创建异常档案。

### 方案管理

方案用于保存常用的角色练度默认值，手动应用到当前角色。可设置突破、核心、好感度、战斗力、技能、魔方和收藏品等字段。

默认只填空缺；启用强制替换时覆盖方案中已填写的字段。方案留空的字段不会清掉原数据，魔方和收藏品按成组信息处理。

方案不包含装备词条，也不改变存档共通的同步器等级或研究等级。

### BOT 分享

角色数据分享码可携带所选角色的装备及勾选字段，供 QQ 机器人导入。单次最多 10 名角色；没有勾选的字段可能在 BOT 侧使用默认值，请先阅读页面说明。

表格配置码只携带角色身份和顺序，优先采用统计页中的已选名单。不完整的已选角色暂不导出，补齐后恢复；名单全部暂停时不会擅自换成其他角色。

自定义妮姬仅供本机使用，不进入 BOT 分享。常用指令示例会显示在页面中，例如 `/妮姬导入 <分享码>` 与 `/妮姬练度统计`；实际执行取决于所使用机器人的支持情况。

### 新增妮姬

可以为本地角色库新增自定义妮姬，填写名称、属性、企业、职业、爆裂阶段和品质等资料，武器及头像／立绘为可选项。

图片支持 PNG、JPEG、WebP，单张不超过 10 MB，支持透明立绘并保留原图。保存后加入本机列表、搜索、筛选、录入及角色详情。

可以编辑、删除或恢复用户创建的角色；内置角色不可删除。删除自定义角色不级联清掉各存档已有记录，恢复时沿用原身份和图片。

自定义角色资料和图片存在独立本机角色库中，所有角色存档共用；普通档案 JSON 不包含这份角色库。

### 关于与更新记录

“关于”集中展示软件版本、作者、项目 GPL v3 许可、第三方来源、许可全文及随附源码下载。原先分散在计算器页脚的长篇来源和许可说明已移入这里，功能页继续保留计算限制。

“注意事项”保留游戏素材与商标权利归属说明。第三方原有许可不会因为本项目采用 GPL 而被改写。

“更新记录”用于查看已维护的版本说明；当前没有自动联网检测和下载安装更新的功能。

| --- | --- | --- |
| 角色记录、存档信息、方案 | 当前客户端的持久数据目录 | 在存档管理中导出各份档案 JSON |
| 自定义角色资料和图片 | 同一持久目录中的本机角色库 | 完全退出客户端后备份完整持久目录；普通档案 JSON 不包含它 |
| 订制模组记录 | 持久目录下 `tools/resource-income.json` | 工具内导出 JSON，也可退出后随完整数据目录备份 |
| 采集截图和日志 | 缓存或用户设置的截图目录 | 需要长期保留的图片主动导出，不能把临时截图当档案备份 |

安装版默认将持久数据保存在 %LOCALAPPDATA%/NIKKE Photos Data/userdata，数据位置配置位于同级 storage-location.json。软件支持原位接续旧版 data 目录；接续后继续使用原目录。可通过客户端菜单打开实际数据目录或接续旧版目录。

复制完整数据目录前应完全退出客户端，避免复制仍在写入的数据库。不要把 `data/` 当作缓存删除，也不要用另一份开发副本的 `data/` 覆盖自己的记录。安装或覆盖更新不会自动合并其他客户端的档案；需要迁移角色记录时，先导出 JSON 再明确选择导入目标。

## 桌面使用说明

- 顶部可切换深色／浅色主题，界面使用简体中文。
- 完整客户端的计算和识别资源均随包提供，日常使用无需在线服务登录。装备采集需要游戏已启动，并由本人确认 UAC。
- 客户端菜单可打开实际数据目录和缓存目录。截图缓存不能替代角色档案备份。
- 遇到识别或保存异常，请保留错误提示与相关截图；不要通过删除整个数据目录排错。
- 程序未使用代码签名证书；是否信任文件应以下载来源和发布方提供的 SHA-256 为依据。
